Coverage interpretation

What this report does—and does not—certify

Completed decision

Each priority scenario has an evidence-backed release-gate outcome. A single mandatory failure is sufficient to fail a scenario; dependent unsafe or impossible branches remain explicitly blocked.

Not a full-cell pass

The large source inventories and every viewport-expanded lifecycle cell are not represented as passed. Only exact actor, fixture, action, state and viewport matches from the preceding 24 hours were reused.

Chrome-only scope

This campaign does not certify Safari, Edge or physical iOS/Android devices. It follows the agreed Chrome-only, six-size scope.

Method, provenance & history

Execution contract

Actual rendered Chrome UI on one computer, with normal logout/login role handoffs. Automation was limited to fixture setup and the explicitly approved synthetic file chooser.

Data safety

Only disposable subjects were locked, revoked or blocked. The account and device were restored; the revoked disposable session stayed revoked. No shared password was changed.

Evidence

Detailed private run records remain under tests/e2e/admin/ in the webapp project. This public report contains sanitized summaries only.
